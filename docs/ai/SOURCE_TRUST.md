# Source Trust

## Proposed hierarchy

Highest to lowest default trust:

1. Official school portal
2. Official school email
3. Official school document
4. Official school website
5. Teacher-originated shared content
6. Parent WhatsApp group
7. Manual user entry

This hierarchy is a prior, not an automatic verdict. Identity/authenticity must be established; a forwarded or uploaded artifact is not official merely because it looks official. Specificity, applicability, publication time, explicit correction language, corroboration, and user edits influence resolution.

Conflicting claims remain linked and visible. A higher-ranked source can produce a proposed resolution but does not silently delete lower-ranked evidence. Manual entries remain valid user intent and require confirmation before replacement.

Source trust informs interpretation but does not grant data access or authorize extraction reuse. Reuse additionally requires compatible scope and account policy as defined in [AI_PIPELINE.md](AI_PIPELINE.md#deduplication-and-privacy-safe-reuse).

Portal and website sources are future scope; WhatsApp is future user-shared content. MVP uses official email/document where verified and manual context. Sender/domain verification, teacher verification, trust scoring, and automation thresholds are **TBD**.
